# Life Planner

A responsive, mobile-first planner dashboard (tasks, calendar, habit tracker, notes).

## Run
Open `index.html` in any modern browser. No build step.

## Notes
- Needs an internet connection on first load (Tailwind CSS CDN and Google Fonts).
- Tasks, events and habits are saved in the browser's localStorage.
- Layout: desktop 1024px+, tablet 768-1023px, mobile below 768px.
